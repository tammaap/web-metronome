# Web Metronome

A browser-based metronome built with HTML, CSS and JavaScript.

## Features
- Adjustable tempo from 20–280 BPM
- Visual tempo indication (Lento, Largo, Andante, Allegro, etc.)
- Start / Stop control
- Spacebar shortcut for Start / Stop
- Adjustable beats per bar
- Visual beat indicators
- Web Audio API for accurate click timing
