# Web Metronome

A web-based metronome focused on clear visual feedback and easy control.

## Features
- Adjustable tempo from 20–280 BPM
- Large BPM display
- Visual beat indicators
- Multiple time signatures
- Tap Tempo
- Tempo markings
- Keyboard shortcuts
- Web Audio API for accurate click timing

## Tech
- HTML
- CSS
- JavaScript
- Web Audio API


## Keyboard Shortcuts

| Key | Action |
|---|---|
| Space | Start / Stop |
| T | Tap Tempo |
| ← / → | Change BPM by 1 |
| Shift + ← / Shift + → | Change BPM by 10 |
| ↑ / ↓ | Change time signature |
